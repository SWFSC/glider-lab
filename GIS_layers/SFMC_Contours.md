1. In SFMC, navigate to Map Layer Settings > Create WMS Layer Setting
2. Enter the following information
- WMS Layer Name: Contours
- URL: https://tiles.arcgis.com/tiles/C8EMgrsFcRFL6LrL/arcgis/rest/services/GEBCO_contours/MapServer/tile/{z}/{y}/{x} 
- Layers: 0,1,2,3,4,5
- Leave the rest as default settings
<img width="1290" height="756" alt="image" src="https://github.com/user-attachments/assets/5c0e0be6-1cf2-4db2-a411-6f90bee5b78c" />

3. Click 'Create' and you should now see the Contours layer as an option on the SFMC maps
